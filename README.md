# 🕰️ Машина времени — сайт-поздравление к юбилею

Один экран, один ползунок по годам — от рождения до сегодняшнего дня.
При перемещении ползунка меняются фон, фото, возраст, город, семейные
события и играет хит того периода (через встроенный плеер Яндекс.Музыки).

Работает без сборки и без бэкенда — чистые HTML/CSS/JS. Готов к публикации
на **GitHub Pages**.

---

## 1. Что нужно сделать перед публикацией

Всё содержание сайта лежит в одном файле — **`data.json`**. Откройте его
в любом текстовом редакторе и замените всё, что написано в квадратных
скобках `[ЗАПОЛНИТЕ...]`, на настоящие данные:

- `person.name` — имя мамы (как обращаться в заголовке);
- `person.birthDate` — точная дата рождения `ГГГГ-ММ-ДД` (от неё считается
  возраст на каждый год);
- `person.finalMessage` — текст поздравления, который появится на финальном
  экране (когда ползунок доедет до сегодняшнего года);
- внутри каждого объекта в `periods[]`:
  - `location` — город/место в этот период;
  - `events[]` — 2–4 коротких пункта о том, что происходило (переезды,
    рождение детей, важные события);
  - `photo` — путь к фотографии, см. раздел 2 ниже;
  - `song` — хит тех лет, см. раздел 3 ниже.

Границы периодов (`startYear` / `endYear`) и их количество — тоже можно
менять свободно, структура это выдержит. Только не удаляйте запятые и
кавычки — это формат JSON, можно проверить себя на https://jsonlint.com.

## 2. Фотографии

Положите фотографии в папку `assets/photos/` и укажите путь к каждой в
поле `photo` соответствующего периода в `data.json`, например:

```json
"photo": "assets/photos/p1.jpg"
```

Если файла по указанному пути нет — на его месте аккуратно показывается
плейсхолдер с подписью «Добавьте фото …», сайт не сломается. Так что можно
публиковать сайт и добавлять фото постепенно.

Совет: используйте фотографии вертикальной или близкой к 4:5 ориентации —
рамка под фото именно такой формы. Для веса сайта лучше сжать фото до
~1500px по длинной стороне (например, через https://squoosh.app).

## 3. Музыка (виджет Яндекс.Музыки)

7 из 8 периодов уже подключены к реальным трекам (зарубежные хиты
соответствующих лет: ABBA, Michael Jackson, Whitney Houston, Céline Dion,
James Blunt, Ed Sheeran, Dua Lipa) — можно оставить как есть, а можно
заменить на что угодно своё. Последний период («Сегодня — 55!») оставлен
пустым специально — туда логично поставить настоящую любимую песню мамы.
Чтобы заменить любой трек — впишите новые `yandexTrackId` / `yandexAlbumId`
вместо старых, это займёт минуту:

1. Откройте **music.yandex.ru**, найдите нужный трек (свой вариант или
   предложенный мной — можно оставить, можно заменить на реальный хит того
   года или просто любимую мамину песню).
2. Посмотрите на адрес страницы трека — он выглядит так:
   `https://music.yandex.ru/album/АЛЬБОМ_ID/track/ТРЕК_ID`
3. В `data.json` впишите эти два числа в поля:
   ```json
   "yandexTrackId": "ТРЕК_ID",
   "yandexAlbumId": "АЛЬБОМ_ID",
   "verified": true
   ```
   (`verified: true` включает показ плеера вместо ссылки-заглушки).

Пока `yandexTrackId`/`yandexAlbumId` не заменены — вместо плеера будет
аккуратная карточка со ссылкой на поиск этого трека в Яндекс.Музыке, сайт
от этого не сломается.

> Если у Яндекс.Музыки в вашем регионе доступа изменится формат ссылок —
> ищите на странице трека кнопку «Поделиться» → «Код для вставки»: там
> Яндекс сам генерирует готовый `<iframe>`, его можно целиком вставить в
> `script.js` вместо автоматически собираемого (функция `setSong`).

## 4. Проверка перед публикацией

Браузеры блокируют `fetch('data.json')` при открытии файла напрямую
(`file://…`), поэтому для проверки нужен локальный сервер. Из папки
проекта выполните одну из команд:

```bash
python3 -m http.server 8000
# или
npx serve .
```

Откройте `http://localhost:8000` — и проверьте, что ползунок двигается,
данные меняются, плеер играет.

## 5. Публикация на GitHub Pages

```bash
# 1. Внутри папки проекта — инициализировать репозиторий
git init
git add .
git commit -m "Машина времени — сайт к юбилею"

# 2. Создать пустой репозиторий на github.com (кнопка New repository),
#    без README/лицензии — просто пустой. Затем подключить его:
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПО.git
git push -u origin main
```

Дальше на GitHub: **Settings → Pages → Source: Deploy from a branch →
Branch: `main` / `root`** → Save.

Через 1–2 минуты сайт будет доступен по адресу:
`https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/`

Если хотите, чтобы сайт открывался сразу по адресу
`https://ВАШ_ЛОГИН.github.io/` (без имени репозитория) — назовите
репозиторий `ВАШ_ЛОГИН.github.io`.

После этого репозиторий можно сделать приватным, если не хотите, чтобы код
был виден всем — сама страница на GitHub Pages при этом всё равно будет
доступна по ссылке (если не включить приватные Pages, доступные только
на платных тарифах).

## 6. Дальнейшие правки

- Хотите больше/меньше периодов — добавьте/удалите объекты в `periods[]`
  в `data.json` (не забудьте, чтобы `startYear`/`endYear` шли подряд без
  разрывов).
- Хотите поменять палитру — в начале `style.css` есть блок `:root` с
  переменными `--pink-1`, `--blue-1` и т.д.
- Скорость авто-прокрутки при нажатии «В полёт по годам» регулируется в
  `script.js`, функция `startPlaying()`, переменная `stepDelay`.

Файловая структура:

```
mama-time-machine/
├── index.html      — разметка страницы
├── style.css       — стили (розово-голубая палитра, стекломорфизм)
├── script.js       — логика слайдера, анимаций, плеера
├── data.json       — ВСЁ содержание сайта (текст, годы, музыка) — правите только этот файл
├── assets/photos/  — сюда кладёте фотографии
└── README.md       — этот файл
```
